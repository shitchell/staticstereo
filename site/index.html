Stereo

The gap between sepFar and sepNear is the whole depth budget — about 18px. Widening it reads as "deeper" but artifacts grow and fusion gets harder. depthBlur is 0 by default: at an 18px budget it was compared by eye and the blur's own depth gradient reads as a slope, so an object meant to float flat looks like a mesa instead — raise it only if widening the budget makes the edge echo visible. freeze noise reuses one dot field for every frame: much easier to fuse, but the shape becomes visible as motion to a single eye.

Diagnostics

The horizontal repeat period is the encoded depth. n is how many pixel comparisons the measurement rests on — a period scored over 20 of them is not the same claim as one scored over 400.

Measure a band, not a whole row. A full-width row crosses both the object and the background, and only one period can best explain it — which will be the background's, since the background is the larger share. So the full-row reading reports sepFar × noiseScale almost everywhere, and the object shows up only as the match percentage dropping. To see sepNear × noiseScale you have to measure inside the shape: click the stereogram to put the band there, or type the range below.

Export & share

GIF is lossless for this payload — a stereogram frame is binary black and white, so a two-colour palette is exact. Export runs on this thread, so a long scene will freeze the page while it encodes.

Scene JSON

The whole scene, editable. This is also what the link in your address bar carries, so anything you can type here is shareable. type: "image" and type: "gif" layers work with an absolute URL or a data: URI (subject to CORS); type: "draw" is deliberately unsupported.
